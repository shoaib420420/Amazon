# Amazon Clone Website

A focused, responsive frontend clone of the Amazon homepage, built to replicate the core visual structure and responsiveness of the original site.

## 📖 Project Overview

This project is a static web application that mimics the layout and design of Amazon's desktop and mobile interfaces. It demonstrates proficiency in modern CSS layout techniques (Flexbox), responsive design, and DOM structure.

## ✨ Features

- **Responsive Navigation Bar**:
  - Includes location selector, search bar with category dropdown, and account/cart icons.
  - Adapts layout for tablet and mobile screens (stacking elements vertically).
- **Interactive Hero Section**:
  - Full-width hero image with overlay message.
- **Product Grid Layout**:
  - Responsive grid system for product cards ("Deals").
  - Hover effects on cards (`.box`) and links.
- **Robust Footer**:
  - Multi-column footer links organized by category.
  - "Back to Top" functionality (visual only).
- **Mobile Adaptation**:
  - Custom media queries (`max-width: 1024px`, `768px`, `480px`) ensure the site looks good on all devices.
  - Hides non-essential elements (like delivery location) on very small screens.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure (header, footer, nav).
- **CSS3**:
  - Flexbox for alignment and spacing.
  - CSS Variables and specific color codes (#007185, #222f3d, etc.) to match Amazon's branding.
  - Media Queries for responsiveness.
- **Font Awesome**: Version 6.7.2 for icons (cart, search, bars, location).

1. **Clone the repository** (or download the files):
   ```bash
   git clone <repository-url>
   ```
2. **Open the project**:
   - Navigate to the project folder.
   - Double-click `index.html` to open it in your default web browser.
   - Alternatively, use a VS Code extension like "Live Server" for a better development experience.
